# again!

A personal, localhost-first developer practice app that combines conceptual quiz cards (multiple choice, True/False, and fill-in-the-blanks) with an interactive coding workbench for analytical SQL and Python.

It automatically turns study notes from an Obsidian vault into tailored practice questions and coding challenges using a custom workspace subagent.

---

## At a Glance

- **COding Practice**: SQL and Python coding challenges paired with active concept recall (MCQ, True/False, fill-in-the-blanks).
- **Notes Pipeline**: Course notes written in Obsidian act as the single source of truth; a workspace subagent parses them and seeds new problems via the internal API.
- **Localhost-First**: Zero cloud hosting fees, fast execution, full privacy, and safe transactional rollback for SQL queries.
